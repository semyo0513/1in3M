# 🏮 34만 분의 1 : 진주 (1 in 340,000 : JINJU)

> **"세계 80억 명 중 하나로 태어나듯, 당신은 진주시민 33만 4천 명 중 한 사람으로 태어났습니다."**  
> 경상남도 진주시의 실제 공공데이터와 지역 갈등 현안을 바탕으로 제작된 **웹 기반 인생 & 정책 시뮬레이션 게임**입니다.  
> 글로벌 화제작 **'80억 분의 1(1 in 8 Billion)'**의 미니멀 텍스트 UI/UX와 시간 감성을 계승하고, 진주시의 공간적 특성을 초정밀 반영했습니다.

---

## ✨ 핵심 특징

1. **무작위 출생의 숙명 (진주시 실제 공공데이터 100% 반영)**
   - 30개 읍·면·동의 실제 출생아 가중치(연간 1,855명 코호트)에 따라 충무공동(혁신도시), 평거동, 초장동, 성북동(원도심), 수곡면(농촌) 등에서 무작위 출생
   - 가구 소득 분위(1~5분위), 부모의 직업군(공공기관, 제조 연구원, 전통시장 상인, 스마트팜 농업 등), 타고난 기질 부여

2. **남강처럼 잔잔히 흐르는 시간 (1분 = 1년)**
   - 1년에 한 살씩 나이를 먹으며 펼쳐지는 생애주기별 인카운터 (0세부터 80+세까지)
   - 재생/일시정지(스페이스바) 및 0.5x, 1x, 2x 배속 지원
   - 매년 초점 선택 (`배움과 탐구`, `일과 벌이`, `사람과 관계`, `몸과 마음`, `이사와 변화`)

3. **동시 출생 코호트 (같은 해 태어난 4명의 동갑내기)**
   - 나와 같은 해 진주에서 태어난 동갑내기 4명이 실시간으로 삶을 살아가는 모습을 대조
   - 같은 정책 발표라도 다른 동네, 다른 직업을 가진 시민에게 어떻게 다르게 닿는지 체감

4. **진주시 6대 핵심 대립 현안과 나비효과 (Dilemma)**
   - **엄격한 중립성 보장:** `FACT`(공식 보도/통계), `STANCE`(양측 대립 입장), `CHOICE`(나의 3단계 선택), `WHATIF`(정책 나비효과)
   - ① 생활폐기물 소각장 (단독 vs 광역화 vs 내동면 갈등)
   - ② 충무공동 혁신도시 인프라 집중 vs 원도심 공동화와 폐교 위기
   - ③ 서부경남 공공병원(진주의료원 후속) 신설 vs 시 재정 건전성
   - ④ 청년 일자리 (공기업 올인 vs 우주항공/바이오 vs 전통가업 vs 탈진주)
   - ⑤ 시내버스 완전공영제/무상교통 vs 도로망 확장/자가용
   - ⑥ 남강유등축제/대첩광장 상업화 vs 원형 보존과 시민 휴식권

5. **5·15·30·50·70세 생각 멈춤 성찰 모달**
   - 생애 중요 길목마다 던져지는 질문과 나의 한 줄 메모 각인

6. **생애 데이터 영수증 (Life Data Receipt) & 남강 유등 추모관**
   - 삶이 끝나면 출력되는 감성적인 영수증 포맷의 인포그래픽 리포트 (클립보드 복사 가능)
   - 남강의 밤 물결 위에 내 생애를 기리는 유등 띄우기 및 브라우저 영구 보존

7. **Web Audio API 앰비언트 사운드**
   - 외부 음원 파일 없이 순수 브라우저 오디오 합성으로 구현된 잔잔한 남강 물결 소리와 감성 펜타토닉 피아노 BGM

## 🛠️ 기술 스택

- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS (미니멀 다크 모드, 감성 타이포그래피)
- **Icons:** Lucide React
- **Audio:** Web Audio API (합성 핑크 노이즈 & 오실레이터 화음)
- **Deployment:** GitHub Pages (상대 경로 `./` 지원 및 GitHub Actions 워크플로 포함)

## 🌐 깃허브 배포 방법 (GitHub Pages)

본 저장소에는 `.github/workflows/deploy.yml` 파일이 포함되어 있어 깃허브에 푸시하면 자동으로 배포됩니다.

1. **깃 저장소 초기화 및 커밋:**
   ```bash
   git init
   git add .
   git commit -m "feat: 34만 분의 1 : 진주 게임 첫 릴리스"
   ```

2. **깃허브 저장소 연결 및 푸시:**
   ```bash
   git remote add origin https://github.com/<당신의-계정>/<저장소-이름>.git
   git branch -M main
   git push -u origin main
   ```

3. **GitHub Pages 설정 활성화:**
   - 깃허브 저장소 웹페이지 ➔ **Settings** ➔ **Pages**로 이동합니다.
   - **Build and deployment** 항목의 **Source**를 `GitHub Actions`로 선택합니다.
   - 푸시 후 잠시 기다리면 Actions 워크플로가 빌드를 완료하고 배포 URL이 활성화됩니다.
