# 진주 인생 시뮬레이션 데이터셋 v0.1 (2026-10-28)

`jinju_life_sim_plan.md`(기획서)에 맞춘 CSV 20개입니다. 모두 UTF-8(BOM)이라 엑셀에서 한글이 바로 열립니다.

## 먼저 알아둘 것

1. **진주시 통계데이터 포털(statdata.jinju.go.kr)은 열람하지 못했습니다.** 진주시청 사이트도 자동 접근을 막습니다. 포털 자료는 이 데이터셋에 반영되지 않았습니다.
2. 핵심 근거는 업로드하신 **2024 진주시 지역사회 건강통계(PDF)** 입니다. 가구 수·주거(2분류)·건강지표·사망원인·소득/학력/직업별 층별 값은 여기서 추출했고 합계·교차 검증을 마쳤습니다.
3. **동별 인구, 학교수, 기대수명(진주), 소득수준(동별)은 확보하지 못했습니다.** 빈칸으로 두고 `91_data_gaps.csv`에 이유와 받을 곳을 적었습니다. 포털에서 내려받은 값은 `92_region_stats_import_template.csv`에 붙여넣으면 됩니다.
4. 건강조사는 **시 단위 표본(905명)** 이라 읍면동별 질병 수치는 없고 동/읍·면 2구분까지만 있습니다.
5. 표본 구성(`08`)과 이를 쓴 일부 가중치(`09`)는 19세 이상 비가중 표본이라 **출생 가구의 분포와 다릅니다**. `quality` 열로 구분했습니다.
6. 게임 권역(GR1~GR6) 분류, 노출도(`23`), 설정값(`20`), 개인 사건(`25`)은 **설계값**이며 실제 통계가 아닙니다.

## 파일 구성

`00_data_catalog.csv`에 파일별 설명·출처·상태·기획서 연결 장을 정리했습니다.

## 데이터 사용 규칙 (권장)

| 규칙 | 내용 |
|---|---|
| 빈칸 | 미확보는 0이 아니라 빈칸, `status`로 표시 |
| reliability | `LOW(RSE>=30)`는 보정 보류 또는 약하게 적용 |
| 보정 상한 | 건강 보정치(`10`)는 ±30% 안에서만 적용 |
| 사망원인 | `06`은 사인 구성 가중치로만 사용(절대 확률 아님), 자살 행은 교육용 모드 제외 |
| 갱신 | `LIVE` 이슈는 14일마다 재확인 |
